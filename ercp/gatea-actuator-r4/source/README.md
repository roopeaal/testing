# ERCP Gate-A Actuator R4

Prospective same-runner randomized active/sham experiment. An earlier timing receiver is measured on a deterministic 16 MiB mmap file on one GitHub-hosted runner, frozen before either future drand source exists, then the same runner and same file receive a later target-dependent active/sham CPU+memory intervention.

Primary inference conditions on the frozen receiver and the realized future target and exactly enumerates the 2^28 QRM28 assignment messages. Only the randomized actuator interaction is confirmatory. Source-main and assignment-main effects are diagnostics.

A positive result is only a candidate anomaly requiring independent preregistered replication; a null is not a general no-retrocausality theorem.
